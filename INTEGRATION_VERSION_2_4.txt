VERSION 2.4 — CORRECTION DE L'EXCEPTION ADMIN

Le retour utilisateur indique que le clic droit reste bloqué alors que l'espace Créateur est ouvert.
Cette version rend la détection admin plus robuste : l'exception est activée après validation du PIN,
et la protection vérifie également que le panneau Créateur est effectivement ouvert.

À remplacer dans GitHub :
- creator.js
- protection.js

Conserver index.html, creator.css et les autres fichiers.
Après commit et publication GitHub Pages :
1. Ouvrir le site.
2. Faire Ctrl+F5.
3. Ouvrir Espace Créateur et saisir 0342.
4. Une fois le panneau visible, tester le clic droit puis F12.
5. Fermer le panneau : la protection visiteurs se réactive immédiatement.

Si le clic droit reste bloqué, vérifier dans l'onglet Network que creator.js ET protection.js sont bien chargés depuis la même version et sans erreur 404.
Le système reste dissuasif, non une sécurité serveur.
