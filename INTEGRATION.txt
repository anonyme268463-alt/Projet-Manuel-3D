INTÉGRATION DANS LE DÉPÔT GITHUB

1. Déposer `creator.js` et `creator.css` à la racine, au même niveau que `index.html`.
2. Dans `index.html`, dans le <head>, après styles.css, ajouter :
   <link rel="stylesheet" href="./creator.css">
3. En bas de `index.html`, après le script app.js, ajouter :
   <script type="module" src="./creator.js"></script>
   Ne pas supprimer onboarding.js ni protection.js.
4. Vérifier que le projet Firebase est bien `guide-3d`.
5. Pour permettre les opérations CRUD, Firestore doit autoriser les lectures et écritures. Le fichier firestore.rules fourni ouvre TOUTE la base à tout Internet. Ne le publier que si tu acceptes ce risque. Le PIN 0342 n'est pas une sécurité serveur.
6. Publier GitHub Pages et tester : bouton « Espace Créateur » > PIN 0342 > créer un véhicule de test > actualiser > supprimer le test.
7. Exporter une sauvegarde JSON avant tout import important.
