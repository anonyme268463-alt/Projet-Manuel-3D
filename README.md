# Manuel 3D — prototype

Prototype indépendant de démonstration pour l'assemblage fictif d'une cuisine de van.

## Utilisation
Ouvrir via un serveur local (ex. `python -m http.server 8000`), puis visiter `http://localhost:8000`.
Le moteur 3D est chargé depuis un CDN : connexion Internet requise.

## Publication
Importer `index.html` et `README.md` dans le dépôt, puis activer GitHub Pages depuis la branche main.

**Attention** : données fictives, pas de procédure officielle, aucun raccordement technique autorisé sur cette base. Ne pas publier de documents ou photos internes sans accord.
